    Python API¶

    There are two ways to use fair-shares from your own code, and they have very different requirements.

    The allocation functions, on data you supply¶

    The allocation functions take population (and, for capability-adjusted approaches, GDP) as pandas dataframes and hand back a result object. They read no files, need no data directory, and take no configuration. A plain pip install "fair-shares @ git+https://github.com/setupelz/fair-shares" is enough, and the code below runs from any directory:

    Python
    import pandas as pd
from fair_shares.library.allocations.budgets.per_capita import equal_per_capita_budget

years = [str(y) for y in range(2020, 2051)]
population = pd.DataFrame(
    [[50.0] * len(years), [10.0] * len(years)],
    index=pd.MultiIndex.from_tuples(
        [("AAA", "million"), ("BBB", "million")], names=["iso3c", "unit"]
    ),
    columns=years,
)

result = equal_per_capita_budget(
    population_ts=population,
    allocation_year=2020,
    emission_category="co2-ffi",
)

print(result.relative_shares_cumulative_emission["2020"])

    Country AAA gets 50/60 of the budget, BBB gets 10/60. Multiply those shares by your global budget to get absolute numbers. The dataframe needs one row per country, a two-level index of country code and unit, and one column per year labelled as a string.

    The full set is in Budget Functions and Pathway Functions.

    The orchestrated timeseries API¶

    calculate_allocation_timeseries runs one allocation end to end in memory: the budget allocation, each country's remaining budget after observed emissions, and an annual pathway that spreads it. It takes one budget anchor (rcb_source, climate_assessment, quantile), one emission category and one approach with scalar parameters. It reads processed data from disk and builds it on the first run. Notebook 601_reproduce_esabcc_2023 calls the same remaining-budget and pathway functions for its whole grid. tests/integration/test_python_api_reproduces_notebook.py checks that the single-allocation route gives the same numbers as the notebook's grid run. If you change either, regenerate its fixtures with uv run python tests/fixtures/save_python_api_fixture.py.

    Python
    from fair_shares.library.python_api import calculate_allocation_timeseries

result = calculate_allocation_timeseries(
    emission_category="co2-ffi",
    rcb_source="lamboll_2023",
    climate_assessment="1.5C",
    quantile=0.5,
    allocation={
        "equal-per-capita-budget": {
            "allocation_year": 2020,
            "preserve_allocation_year_shares": False,
        }
    },
    shape="half-sine",            # how the pathway redresses past over-use
    deviation_end_year=2050,      # year that redress ends
    convergence_year=2050,        # year per-capita emissions converge
    nonco2_debt_mode=None,        # "report-only" or "co2-debit" for all-GHG categories
    pathway_end_year=2100,
    base_share_floor_mt=0.001,    # floor for net-sink countries' starting share
    desired_harmonisation_year=2020,
    emissions_source="primap-202609",
    gdp_source="wdi-2025",
    population_source="un-owid-2025",
    gini_source="wdi-2025",
    lulucf_source="melo-2026-v4",
    allocation_folder="my-run",
)

pathways = result.allocation_timeseries   # one row per country, one column per year
in_2030 = pathways["2030"].groupby(level="iso3c").sum()   # Mt CO2 in 2030
print(in_2030[["IND", "USA", "DEU"]])

    The distribution settings are normative choices. Outputs lists what the result holds, and EU budgets sums the result over a group of countries. Loop over approaches, anchors and settings to build a larger set. Parameter grids and pathway targets run in the notebooks.

    Inside a checkout the function finds data/ and output/ itself. From an installed package, set FAIR_SHARES_DATA_DIR and FAIR_SHARES_OUTPUT_DIR, or pass data_dir= and output_dir=. Building missing processed data needs Snakemake, from the pipeline extra.

    Presets¶

    A preset holds the parameter set of a published study, because several library defaults differ from published settings. fair_shares.library.presets holds the ESABCC 2023 preset that notebook 601 runs. esabcc_2023_allocations(category) returns the grid for run_all_allocations, and esabcc_2023_allocation_list(category) the same runs one by one for calculate_allocation_timeseries. The ESABCC presets runs it.

    fair_shares.library.presets.esabcc_2023.esabcc_2023_allocations ¶

    Python
    esabcc_2023_allocations(
    emission_category: str,
) -> dict[str, list[dict[str, list[Any]]]]

    Return the ESABCC 2023 / PRR2023 allocation grid for one emission category.

    The grid is the one notebook 601_reproduce_esabcc_2023 runs. Source: Pelz, Rogelj and Riahi (2023), the equity analysis behind the ESABCC 2023 advice on the EU 2040 target.

    co2-ffi is the report's full matrix: equal per capita (EPC) and equal cumulative per capita (ECPC, population to 2050) budgets from 1990 and 2015; responsibility penalties 1/x and 1/sqrt(x) over 1850-1989 (from 1990) and 1850-2014 or 1990-2014 (from 2015), total and per capita, on both bases; capability penalties 1/x and 1/sqrt(x) on a GDP-per-capita snapshot in 1990 or 2014, on both bases. The two all-GHG categories extend the report. They allocate from 2015 only. all-ghg-ex-co2-lulucf keeps the 1850 and 1990 windows. all-ghg starts its window in 2000, where national land-use data begin.

    Every approach names its functional form ("power"), its responsibility window start or capability snapshot year, and, on the ECPC base, cumulative_end_year=2050, so the library defaults for these parameters do not apply.

    Parameters:

    Name Type Description Default
    emission_category str

    One of "co2-ffi", "all-ghg-ex-co2-lulucf" or "all-ghg".

    		 required

    Returns:

    Type Description
    dict

    Approach name mapped to a list of parameter grids, each value a list. This is the allocations argument of :func:fair_shares.library.notebook_helpers.run_all_allocations. Use :func:esabcc_2023_allocation_list for the single-allocation form that :func:fair_shares.library.python_api.calculate_allocation_timeseries takes. Each call returns a new object.

    Allocation Steps¶

    calculate_allocation_timeseries composes these steps. Call them directly when you already hold an allocations frame.

    compute_remaining_budgets¶

    fair_shares.library.python_api.compute_remaining_budgets ¶

    Python
    compute_remaining_budgets(
    category: str,
    allocations_absolute: DataFrame,
    processed_dir: Path,
) -> DataFrame

    Remaining budget per country after netting observed emissions (§5).

    Budget parts: remaining = allocated total minus actual consumption from the allocation year through the netting end year. Non-CO2 pathway parts: remaining = the forward-window allocation, with the historical deviation (actual minus allocated over the past window) reported separately. Every part nets through the last year that all parts observe (2024 for all-ghg). For composite categories a combined row per configuration is added (CO2 budget part + non-CO2 pathway part), matched on the RCB source, climate assessment, quantile and shared equity params.

    Raises:

    Type Description
    ValueError

    If a budget row of a composite category has no non-CO2 pathway row

    distribute_remaining_pathways¶

    fair_shares.library.python_api.distribute_remaining_pathways ¶

    Python
    distribute_remaining_pathways(
    category: str,
    allocations_absolute: DataFrame,
    remaining: DataFrame,
    processed_dir: Path,
    *,
    distribution_grid: dict[str, Sequence[Any]],
    pathway_end_year: int,
    base_share_floor_mt: float,
    nonco2_debt_modes: Sequence[str]
) -> DataFrame

    Distribute every budget configuration's remaining budget to 2100 (§6).

    Spreads each remaining budget to pathway_end_year across the distribution grid. For composite categories each CO2 configuration is distributed under every nonco2_debt_modes entry (report-only leaves the CO2 budget as is; co2-debit subtracts the country's past non-CO2 over-use and retires it), and the allocated non-CO2 and combined rows are appended.

    build_history¶

    fair_shares.library.python_api.build_history ¶

    Python
    build_history(
    category: str, processed_dir: Path

    Observed emissions for every coverage this category needs (§5 inputs).

    One frame with a (coverage, unit, iso3c) MultiIndex and year columns. The combined basket is the sum of its parts (NaN where either part lacks a year, e.g. the all-ghg basket before the NGHGI CO2 record starts).

    save_results¶

    fair_shares.library.python_api.save_results ¶

    Python
    save_results(
    results: ResultContainer, outpath: Path
) -> Path

    Persist a :class:ResultContainer under outpath (created if needed).

    Writes allocation_timeseries.parquet, history.parquet, a metadata.json of every scalar attribute, and CITATIONS.md listing the software and the data sources this run used. Returns outpath.

    Citing a run¶

    save_results writes a CITATIONS.md next to the results. It lists the software and exactly the data sources the run used. To get the list in code, or from the command line:

    Python
    from fair_shares.library.citations import citations

run = citations(active_sources, emission_category="all-ghg")
print(run.text())     # software, then each data source with DOI and licence
print(run.bibtex())
    Bash
    uv run fair-shares cite --sources gini=wdi-2025,target=pathway --bibtex

    Sources without a DOI (World Bank, OWID, UN WPP) are credited by name. Terms that ask for more than attribution get their own section: the Global Carbon Project's co-authorship request, CMIP7's component datasets, the non-commercial share-alike licence of PRIMAP-hist v2.8, WIID's non-commercial clause and the Scenario Compass embargo terms. Data & licences explains what this means for outputs.
