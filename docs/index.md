# fair-shares

Python library for calculating fair share allocations of global carbon budgets and emission pathways.

fair-shares divides a global carbon budget or emissions pathway between countries or IAM model regions.
Each allocation approach applies stated equity principles, such as equal per-capita entitlements, historical responsibility and capability.
The library fetches the input data, runs the allocations and records every parameter and data source with the results.
It serves researchers and analysts who need national or regional fair share benchmarks they can reproduce.
